Ferrocast is a launcher for macOS written in Rust, inspired by Raycast. It is not a complete replica and it uses no Raycast brand or assets. It searches apps, commands and files, does math, currency and time-zone conversion, keeps clipboard history, expands snippets, manages windows, asks AI models, and converts and edits files locally from a drag-and-drop wheel.

Press <kbd>⌥</kbd> <kbd>Space</kbd> from any app to open it. It is free, MIT licensed, needs no account, and runs on Apple Silicon Macs only. It installs with Homebrew, which compiles it on your Mac.

## Who it is for

People who want a fast, keyboard-driven launcher whose data stays in JSON files on their own disk, and who are fine with Script Commands instead of an extension store. If you live inside Raycast extensions, Ferrocast is not a drop-in replacement yet.

## What it is not

Honestly missing today: an extension store and sync between Macs. React extensions, Search Menu Bar Items and AI context (selection or screen) are not included. Pressing Enter on a Finder selection is not included either; the Convert Finder Selection command exists instead.
