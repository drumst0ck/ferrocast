A quicklink is a saved link that accepts arguments, so a few typed letters take you exactly where you meant to go.

Open Quicklinks from the launcher; <kbd>⌘</kbd> <kbd>N</kbd> creates one and <kbd>⌘</kbd> <kbd>E</kbd> edits the selected one. `{snippet name=…}` resolves in quicklinks.

If you come from Raycast, quicklinks are not imported; recreate them (it takes about a minute). See [Migrating from Raycast](/docs/getting-started/migrating-from-raycast/).

:::caution[Limits]
Quicklinks are not part of the snippet JSON import.
:::
