Window management moves and resizes the frontmost window with about 40 commands: halves, thirds, corners, center, and moving between displays.

Run a command from the launcher by name, or give it its own hotkey with <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>,</kbd> on the selected command. The window switcher command jumps between open windows.

:::caution[Limits]
Needs the Accessibility permission. Window management is **not verified in a real session**.
:::

## Status

**Built.** Implemented; requires Accessibility.
