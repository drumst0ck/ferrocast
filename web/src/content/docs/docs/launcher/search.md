Root search is the main field of the launcher. It finds apps, commands and files, ranks them with fuzzy matching and frecency (how often and how recently you used them), and answers math and currency conversion on the same line. Files come from Spotlight; a pulsing “Searching files” indicator shows while Spotlight answers.

Open the launcher with <kbd>⌥</kbd> <kbd>Space</kbd>, type, move with <kbd>↑</kbd> <kbd>↓</kbd> and press <kbd>↵</kbd> to run the primary action or <kbd>⌘</kbd> <kbd>↵</kbd> for the secondary one. <kbd>⌘</kbd> <kbd>K</kbd> opens the [action panel](/docs/launcher/actions-panel/). A single click runs a list row, and clicks in the 350 ms after a view change are ignored so a habitual double click cannot fire the first row of the new screen.

## Options

- **Aliases and favorites**: give any app or command a short name; <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>F</kbd> adds or removes a favorite (on a file result the same keys run Float on Shelf).
- **Hotkey per command**: <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>,</kbd> sets a hotkey for the selected command.
- **Fallback**: when nothing matches, a “Look up in Dictionary” fallback is offered.
- **Window switcher, notes, emoji and file search** are commands of the same list. See [System commands](/docs/launcher/system-commands/).
- <kbd>esc</kbd> clears the search, goes back or closes; <kbd>⌫</kbd> goes back when the search is empty.
