This page lists the shortcuts in the launcher, in the Notes window and in the file tool windows. Shortcuts are written with macOS glyphs.

## Launcher

| Keys | Action |
|---|---|
| <kbd>⌥</kbd> <kbd>Space</kbd> | Open or close Ferrocast. You can change it in Settings. |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move the selection. |
| <kbd>↵</kbd> | Run the primary action. |
| <kbd>⌘</kbd> <kbd>↵</kbd> | Run the secondary action. |
| <kbd>⌘</kbd> <kbd>K</kbd> | Open the action panel for the selected item. |
| <kbd>⌘</kbd> <kbd>,</kbd> | Open Settings. |
| <kbd>⌘</kbd> <kbd>N</kbd> | New snippet, quicklink or note in those lists. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>F</kbd> | Add or remove a favorite; on a file result it runs Float on Shelf. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>,</kbd> | Set a hotkey for a command. |
| <kbd>esc</kbd> | Clear the search, go back, or close. |
| <kbd>⌃</kbd> <kbd>X</kbd> | Delete the selected entry. |
| <kbd>⌘</kbd> <kbd>Y</kbd> | Quick Look the selected file. |
| <kbd>⌘</kbd> <kbd>.</kbd> | Pin or unpin a clipboard entry. |
| <kbd>⌘</kbd> <kbd>E</kbd> | Edit the selected snippet or quicklink. |
| <kbd>⌫</kbd> | Go back when the search is empty. |

## With the mouse

Every launcher shortcut above has a click path too, so you can use Ferrocast without the keyboard.

| Click | Action |
|---|---|
| Right-click (or two-finger click) a row | Select the row and open its action panel, same as <kbd>⌘</kbd> <kbd>K</kbd>. |
| Click a row | Run the primary action, same as <kbd>↵</kbd>. A double click does the same. |
| Click **Actions** in the footer | Open or close the action panel for the selected item. |
| Click **↵** or **esc** in the footer | Run the primary action, or go back. |
| Click outside the action panel | Close it. |
| Hover a clipboard row | **Pin** or **Unpin**, and **Delete** (<kbd>⌘</kbd> <kbd>.</kbd> and <kbd>⌃</kbd> <kbd>X</kbd>). |
| Hover a snippet or quicklink row | **Edit** and **Delete** (<kbd>⌘</kbd> <kbd>E</kbd> and <kbd>⌃</kbd> <kbd>X</kbd>). |
| Click **Clear History…** in the Clipboard view | Delete all clipboard entries after a confirmation. Pinned entries stay (<kbd>⌃</kbd> <kbd>⇧</kbd> <kbd>X</kbd>). |
| Click **+ New** in Snippets or Quicklinks | Create one (<kbd>⌘</kbd> <kbd>N</kbd>). |

Hover any of these buttons to see its name and shortcut.

## Notes window

These work while the [Notes](/docs/launcher/notes/) window is open.

| Keys | Action |
|---|---|
| <kbd>⌘</kbd> <kbd>N</kbd> | New note. |
| <kbd>⌘</kbd> <kbd>P</kbd> | Browse Notes. |
| <kbd>⌘</kbd> <kbd>K</kbd> | Open the action panel. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>P</kbd> | Pin or unpin the note (<kbd>⌘</kbd> <kbd>.</kbd> in the Search Notes list). |
| <kbd>⌘</kbd> <kbd>1</kbd> to <kbd>⌘</kbd> <kbd>9</kbd> | Open the first to the ninth pinned note. |
| <kbd>⌘</kbd> <kbd>[</kbd> <kbd>⌘</kbd> <kbd>]</kbd> | Go back or forward through the notes you opened. |
| <kbd>⌘</kbd> <kbd>+</kbd> <kbd>⌘</kbd> <kbd>-</kbd> <kbd>⌘</kbd> <kbd>0</kbd> | Zoom in, zoom out, actual size. |
| <kbd>⌘</kbd> <kbd>↵</kbd> | Check or uncheck the task on the cursor line. |
| <kbd>⌘</kbd> <kbd>B</kbd> <kbd>⌘</kbd> <kbd>I</kbd> <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>S</kbd> <kbd>⌘</kbd> <kbd>U</kbd> <kbd>⌘</kbd> <kbd>E</kbd> <kbd>⌘</kbd> <kbd>L</kbd> | Bold, italic, strikethrough, underline, code, link. |
| <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>1</kbd> <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>2</kbd> <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>3</kbd> | Heading 1, 2, 3. |
| <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>C</kbd> | Code block. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>B</kbd> | Blockquote. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>7</kbd> <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>8</kbd> <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>9</kbd> | Ordered, bullet and task list. |
| <kbd>esc</kbd> | Close the window (or move focus away, if Settings → Notes → Escape Key Loses Focus is on). |

## Inside the windows

| Window | Keys |
|---|---|
| Any editor | <kbd>↵</kbd> writes the copy and never overwrites; <kbd>esc</kbd> goes back. |
| Drag wheel | Arrow keys choose, <kbd>↵</kbd> applies, <kbd>esc</kbd> cancels; tapping <kbd>⇧</kbd>, <kbd>⌘</kbd> or <kbd>⌃</kbd> switches wheel. |
| Video trim and split | <kbd>←</kbd> <kbd>→</kbd> step a frame, <kbd>⇧</kbd> <kbd>←</kbd> <kbd>→</kbd> step a second, <kbd>I</kbd> <kbd>O</kbd> set markers (trim), <kbd>M</kbd> adds a cut and <kbd>⌫</kbd> removes the last (split), <kbd>Home</kbd> <kbd>End</kbd> jump. |
| PDF organizer | <kbd>R</kbd> rotate, <kbd>⇧</kbd> <kbd>R</kbd> rotate back, <kbd>D</kbd> duplicate, <kbd>⌫</kbd> remove, <kbd>⌘</kbd> <kbd>←</kbd> <kbd>→</kbd> move the page. |
| Choose Order | <kbd>⌘</kbd> <kbd>↑</kbd> <kbd>⌘</kbd> <kbd>↓</kbd> move the row. |

:::note[Enter on a Finder selection]
<kbd>↵</kbd> on selected files in Finder opens the Convert wheel instead of renaming when you turn on Settings > General > “Enter on Finder selection” (off by default, needs Accessibility).
:::
