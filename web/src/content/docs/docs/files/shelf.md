The File Shelf keeps files at hand. It exists as a persisted list inside the launcher (File Shelf command) and as a floating panel: a native always-on-top panel pinned to a screen edge where you drop files in and drag them out.

Run **File Shelf** from the launcher, or use Float on a file result or from the Actions wheel. Drop files on the open shelf to add them. Every file action works on shelf items; Remove and Clear never touch the files themselves.
