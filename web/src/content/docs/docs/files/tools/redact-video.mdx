The Redact Video window lists areas; each has its own draggable rectangle, start and end seconds, and a solid or blur cover. A Reference frame slider picks which frame is shown.

Choose Redact Video… on a video; <kbd>↵</kbd> writes the copy and never overwrites. Typed: `redact 10,10 200x100 0:05-0:09 blur`. Up to 64 areas.

<ToolFacts id="redactVideo" />

## Options

- Overlapping areas and rotated video are handled by the executor.

:::caution[Limits]
The preview only marks the areas. Dragging and keys are not tested in a real session. The reference frame has no real run against ffmpeg and its latency was not measured.
:::

## Status

**Built.** Implemented; executor tested on real video (pixels, overlapping areas, rotated video), window checked by screenshot and synthetic events.
