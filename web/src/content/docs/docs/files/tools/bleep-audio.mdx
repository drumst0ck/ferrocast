Bleep Audio lists several ranges over the waveform and replaces each with a 1 kHz tone; up to 32 ranges, and overlapping ranges are merged.

Choose Bleep for an audio file. Typed command: `bleep 0:05-0:07`.

<ToolFacts id="redactAudio" />

:::caution[Limits]
Offered for one audio file only; the executor rejects video.
:::
