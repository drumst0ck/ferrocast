Split Video cuts one video into several clips with markers or into equal parts, writing every clip into one new folder named after the file (for example `<name> split`, then `split 2` on collision), never touching the original.

Choose Split from the Tools wheel or the Convert view. <kbd>M</kbd> adds a cut at the cursor, <kbd>⌫</kbd> removes the last, arrows, <kbd>Home</kbd>, <kbd>End</kbd> and clicks seek, <kbd>↵</kbd> splits. An Equal parts box (2 to 50) is used when there are no markers. Typed command: `split 30s`.

## Options

- Fewer than two clips is refused with a message.
