The redaction editor lets you drag areas onto an image, move or resize them and choose a solid colour or a blur. Faces and text can also be found on-device with Vision.

Press <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>R</kbd> on an image result; <kbd>↵</kbd> writes the copy and never overwrites. Typed command: `redact faces`, `redact text blur 25`, `redact 10,10 200x100 300,40 80x80 color ff0000` or `redact 10,10 200x100 blur`.

<ToolFacts id="redactImage" />

## Options

- A Blur slider sets the radius from 2 to 80 px; clicking empty space deselects the area.

:::caution[Limits]
The preview only marks the areas; the cover is applied when saving.
:::
