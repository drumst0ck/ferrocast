The visual PDF organizer shows page thumbnails and lets you rotate, duplicate, remove and move pages.

Press <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>O</kbd> on a PDF result. <kbd>R</kbd> rotates, <kbd>D</kbd> duplicates, <kbd>⌫</kbd> removes, <kbd>⌘</kbd> <kbd>←</kbd> <kbd>→</kbd> moves a page, <kbd>↵</kbd> saves a copy. Typed: `pages 3,1,2r`.

<ToolFacts id="organizePdf" />

## Options

- Pages can be dragged to reorder.

:::caution[Limits]
Rendering was checked by screenshot; keys are not tested in a real session. Dragging was tested only with synthetic pointer events: the real gesture and automatic scrolling with long PDFs are untested, and the PDF written after a drag was not tested, only the plan. A long PDF cannot be dragged past the visible strip: use <kbd>⌘</kbd> <kbd>←</kbd> <kbd>→</kbd>.
:::
