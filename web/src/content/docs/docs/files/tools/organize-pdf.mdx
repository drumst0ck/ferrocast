The visual PDF organizer shows page thumbnails and lets you rotate, duplicate, remove and move pages.

Press <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>O</kbd> on a PDF result. <kbd>R</kbd> rotates, <kbd>D</kbd> duplicates, <kbd>⌫</kbd> removes, <kbd>⌘</kbd> <kbd>←</kbd> <kbd>→</kbd> moves a page, <kbd>↵</kbd> saves a copy. Every key has a button above the strip: **◀ Move**, **Move ▶**, **↺ Rotate**, **↻ Rotate**, **Duplicate** and **Remove** act on the selected page; click a thumbnail to select it. Typed command: `pages 3,1,2r`.

<ToolFacts id="organizePdf" />

## Options

- Pages can be dragged to reorder.

:::caution[Limits]
A long PDF cannot be dragged past the visible strip: use <kbd>⌘</kbd> <kbd>←</kbd> <kbd>→</kbd> or the **◀ Move** and **Move ▶** buttons.
:::
