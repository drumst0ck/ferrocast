[PDF organizer for Mac](/tools/organize-pdf/) is the product page. This page is the reference: keys, the typed command and the limits.

Press <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>O</kbd> on a PDF result. <kbd>R</kbd> rotates, <kbd>D</kbd> duplicates, <kbd>⌫</kbd> removes, <kbd>⌘</kbd> <kbd>←</kbd> <kbd>→</kbd> moves a page, <kbd>↵</kbd> saves a copy and never overwrites. Typed command: `pages 3,1,2r`.

Each action also has a button: ◀ Move, Move ▶, ↺ Rotate, ↻ Rotate, Duplicate and Remove. The keys above do the same thing, and you can drag a thumbnail to reorder.

<ToolFacts id="organizePdf" />

## Options

- Pages can be dragged to reorder.

:::caution[Limits]
A long PDF cannot be dragged past the visible strip: use <kbd>⌘</kbd> <kbd>←</kbd> <kbd>→</kbd>, or the ◀ Move and Move ▶ buttons.
:::
