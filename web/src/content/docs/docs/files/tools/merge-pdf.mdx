Merge combines selected PDFs into one PDF.

Select two or more PDFs and choose Merge in the Convert view; the Choose Order window orders the files with <kbd>⌘</kbd> <kbd>↑</kbd> and <kbd>⌘</kbd> <kbd>↓</kbd>, or by dragging rows.
