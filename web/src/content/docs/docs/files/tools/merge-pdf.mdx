Merge combines selected PDFs into one PDF.

Select two or more PDFs and choose Merge in the Convert view; the Choose Order window orders the files with <kbd>⌘</kbd> <kbd>↑</kbd> and <kbd>⌘</kbd> <kbd>↓</kbd>, or by dragging rows.

<ToolFacts id="mergePdf" />

:::caution[Limits]
Dragging rows was tested only with synthetic pointer events. Enter running the merge is not tested.
:::

**Built.** Implemented; tested with real files (merge then split into 2 pages), window untested live.
