Step-by-step guide: [Make a PDF from images on Mac](/tools/create-pdf/).

Create a PDF combines selected images into one PDF with a page per image.

Select the images and choose Combine into one PDF from the Tools wheel or the Convert view; the Choose Order window orders them with <kbd>⌘</kbd> <kbd>↑</kbd> and <kbd>⌘</kbd> <kbd>↓</kbd> or by dragging.
