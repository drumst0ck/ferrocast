The snapshot viewer selects a frame using the timeline or frame and second stepping, and saves a full-resolution PNG through the existing snapshot tool, keeping the viewer open.

Press <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>S</kbd> on a video result and press <kbd>↵</kbd> to save. Typed: `frame 1:23`.
