The speed window offers a 0.25–4× slider and presets, shows the calculated output duration, and runs the existing pitch-preserving speed tool.

Press <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>L</kbd> on a video result; <kbd>↵</kbd> runs it. Typed command: `speed 1.5x`.

<ToolFacts id="changeVideoSpeed" />

:::caution[Limits]
Requires ffmpeg. The window does not play the video.
:::
