The annotation canvas draws arrows, lines, boxes, ellipses, highlights, freehand, numbered labels and a magnifier with a live preview, and saves a full-size PNG copy. With several images selected, Annotate opens Preview instead.

Press <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>A</kbd> on an image result, or choose Annotate in the Tools wheel or the Convert list; <kbd>↵</kbd> saves and never overwrites.

<ToolFacts id="annotateImage" />

## Options

- Free text with the system Arial font.
- Callouts with a pointer (drag from the target, then type).
- Image stamps from the native file chooser.

## Status

**Tested.** Implemented; drawing verified by screenshot and saving with a real file.
