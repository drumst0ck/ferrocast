Join Videos merges several clips into one video. The first clip sets the canvas, and silent clips get generated silence.

Select several videos and choose Join from the Tools wheel or the Convert view. A Choose Order window lets you order the clips with <kbd>⌘</kbd> <kbd>↑</kbd> and <kbd>⌘</kbd> <kbd>↓</kbd>, or by dragging rows.
