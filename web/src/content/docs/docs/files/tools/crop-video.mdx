The video crop window shows a real frame with a draggable crop rectangle, aspect presets and exact width and height, and keeps audio.

Press <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>J</kbd> on a video result; <kbd>↵</kbd> writes the cropped copy and never overwrites. Typed command: `crop 640x360 at 100,50`. A Reference frame slider (also in Redact Video) picks which frame is shown.

<ToolFacts id="cropVideo" />

## Options

- Rotated phone video is handled: the displayed size swaps width and height for a ±90/270 rotation.

:::caution[Limits]
Needs ffmpeg. The reference frame is fixed at 10% of the duration. WMV fails on crop.
:::
