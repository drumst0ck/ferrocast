Audio to Video builds an MP4 from one audio file using the waveform or a chosen still image, in landscape, portrait or square (Portrait is 720x1280, Square 1080x1080).

Choose Audio to Video for an audio file. Use Choose picture… for a still. Typed command: `visualizer square image /path/cover.jpg`.

<ToolFacts id="audioToVideo" />

:::caution[Limits]
Offered for one audio file only.
:::
