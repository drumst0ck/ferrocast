Extract Archive unpacks zip, tar, tar.gz/tgz and gz (and rar) into a new folder named after the archive, never into an existing one. It first refuses archives with absolute or `..` entry names.

Choose Extract from the Tools wheel or the Convert view for an archive. Name collisions add 2, 3 and so on. RAR is read with the system `tar` first, with `unrar` as fallback.

<ToolFacts id="extractArchive" />

:::caution[Limits]
Symlink entries are left to `tar` and `ditto`. `gz` has no size limit.
:::
