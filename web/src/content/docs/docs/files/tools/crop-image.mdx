The crop editor shows a draggable rectangle with eight handles, aspect presets (1:1, 4:3, 3:2, 16:9, 9:16) and exact width and height boxes.

Press <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>K</kbd> on an image result; <kbd>↵</kbd> writes the cropped copy and never overwrites. Typed: `800x600` for an exact crop.
