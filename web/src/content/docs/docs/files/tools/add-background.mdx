The background editor adds padding, corners and a shadow around an image and sets a colour, a blurred copy or another image as backdrop, with the preview composed on a reduced copy.

Press <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>B</kbd> on an image result; <kbd>↵</kbd> writes the full-size copy and never overwrites. Typed command: `frame blur 40 pad 80 shadow 30`, or `frame image /path/bg.jpg` for another picture. A square white or black background is also a preset.

<ToolFacts id="frameImage" />

## Options

- Backdrop choices: Colour, Blur or Image (Choose image…).
