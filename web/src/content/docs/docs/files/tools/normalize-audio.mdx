The Normalize Audio window sets a target loudness (-30 to -5 LUFS, default -16, presets -23, -16 and -14), a range (1 to 20 LU) and a true peak (-9 to 0 dBTP, default -1.5), after measuring the file.

Choose Normalize from the Tools wheel or the Convert view; the window shows the measured loudness against the target. Typed: `normalize -14`.

<ToolFacts id="normalizeAudio" />

:::caution[Limits]
Normalize is single pass and the toast shows the measured loudness before and after (for example `-31.0 → -16.0 LUFS`, measured with ffmpeg ebur128). There is no waveform or compare view. The window is not tested with real keys or mouse.
:::
