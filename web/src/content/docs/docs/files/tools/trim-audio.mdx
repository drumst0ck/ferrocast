Step-by-step guide: [Trim audio on Mac](/tools/trim-audio/).

Trim Audio shows the waveform with markers, exact start and end boxes and a Trim silence button that removes silence at the ends.

Choose Trim from the Tools wheel or the Convert view for an audio file. Typed command: `trim 0:10-0:30` or `silence`.

<ToolFacts id="trimAudio" />

:::caution[Limits]
The silence threshold is per sample, so a single click shifts it. There is no before and after comparison bar.
:::
