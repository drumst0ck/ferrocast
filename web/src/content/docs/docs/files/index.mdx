Ferrocast converts images, audio, video, documents, spreadsheets, subtitles and folders, and edits them with 26 tools and 7 file actions, all on your Mac. Nothing is uploaded. Built-in macOS tools come first (sips, afconvert, avconvert, textutil, ditto); ffmpeg, LibreOffice and cwebp are optional, and a missing one shows its install command.

Drag files and tap a key: <kbd>⇧</kbd> **Shift** for conversions, <kbd>⌘</kbd> **Command** for file tools, <kbd>⌃</kbd> **Control** for file actions. Or press <kbd>⌘</kbd> <kbd>T</kbd> on a file result, run **Convert Files**, or press <kbd>⌥</kbd> <kbd>↵</kbd> on a file result to open the format wheel.

## Output rules

The result is written next to the original with the same base name and the new extension, and **never overwrites**: if that name is taken it appends 2, 3 and so on. A toast shows the result with a Reveal action.
