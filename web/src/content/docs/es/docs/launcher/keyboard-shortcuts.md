Esta página lista los atajos del lanzador, de la ventana de Notes y de las ventanas de herramientas de archivos. Los atajos se escriben con los símbolos de macOS.

## Lanzador

| Teclas | Acción |
|---|---|
| <kbd>⌥</kbd> <kbd>Space</kbd> | Abrir o cerrar Ferrocast. Puedes cambiarlo en Ajustes. |
| <kbd>↑</kbd> <kbd>↓</kbd> | Mover la selección. |
| <kbd>↵</kbd> | Ejecutar la acción principal. |
| <kbd>⌘</kbd> <kbd>↵</kbd> | Ejecutar la acción secundaria. |
| <kbd>⌘</kbd> <kbd>K</kbd> | Abrir el panel de acciones del elemento seleccionado. |
| <kbd>⌘</kbd> <kbd>,</kbd> | Abrir Ajustes. |
| <kbd>⌘</kbd> <kbd>N</kbd> | Nuevo snippet, quicklink o nota en esas listas. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>F</kbd> | Añadir o quitar un favorito; en un resultado de archivo ejecuta Float on Shelf. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>,</kbd> | Asignar un atajo a un comando. |
| <kbd>esc</kbd> | Borrar la búsqueda, volver o cerrar. |
| <kbd>⌃</kbd> <kbd>X</kbd> | Eliminar la entrada seleccionada. |
| <kbd>⌘</kbd> <kbd>Y</kbd> | Quick Look del archivo seleccionado. |
| <kbd>⌘</kbd> <kbd>.</kbd> | Fijar o soltar una entrada del portapapeles. |
| <kbd>⌘</kbd> <kbd>E</kbd> | Editar el snippet o quicklink seleccionado. |
| <kbd>⌫</kbd> | Volver cuando la búsqueda está vacía. |

## Ventana de Notes

Funcionan mientras la ventana de [Notes](/es/docs/launcher/notes/) está abierta.

| Teclas | Acción |
|---|---|
| <kbd>⌘</kbd> <kbd>N</kbd> | Nueva nota. |
| <kbd>⌘</kbd> <kbd>P</kbd> | Browse Notes. |
| <kbd>⌘</kbd> <kbd>K</kbd> | Abrir el panel de acciones. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>P</kbd> | Fijar o soltar la nota (<kbd>⌘</kbd> <kbd>.</kbd> en la lista de Search Notes). |
| De <kbd>⌘</kbd> <kbd>1</kbd> a <kbd>⌘</kbd> <kbd>9</kbd> | Abrir la primera a la novena nota fijada. |
| <kbd>⌘</kbd> <kbd>[</kbd> <kbd>⌘</kbd> <kbd>]</kbd> | Ir atrás o adelante entre las notas que abriste. |
| <kbd>⌘</kbd> <kbd>+</kbd> <kbd>⌘</kbd> <kbd>-</kbd> <kbd>⌘</kbd> <kbd>0</kbd> | Acercar, alejar, tamaño real. |
| <kbd>⌘</kbd> <kbd>↵</kbd> | Marcar o desmarcar la tarea de la línea del cursor. |
| <kbd>⌘</kbd> <kbd>B</kbd> <kbd>⌘</kbd> <kbd>I</kbd> <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>S</kbd> <kbd>⌘</kbd> <kbd>U</kbd> <kbd>⌘</kbd> <kbd>E</kbd> <kbd>⌘</kbd> <kbd>L</kbd> | Negrita, cursiva, tachado, subrayado, código, enlace. |
| <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>1</kbd> <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>2</kbd> <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>3</kbd> | Encabezado 1, 2, 3. |
| <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>C</kbd> | Bloque de código. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>B</kbd> | Cita. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>7</kbd> <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>8</kbd> <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>9</kbd> | Lista numerada, lista con viñetas y lista de tareas. |
| <kbd>esc</kbd> | Cerrar la ventana (o quitar el foco, si Ajustes → Notes → Escape Key Loses Focus está activado). |

|---|---|

| <kbd>⌥</kbd> <kbd>↵</kbd> | Abrir la rueda de formatos de un resultado de archivo. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>A</kbd> | Lienzo de anotación (imagen). |

| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>K</kbd> | Editor de recorte (imagen). |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>R</kbd> | Editor de ocultación (imagen). |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>B</kbd> | Editor de fondo (imagen). |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>V</kbd> | Visor de recorte de vídeo. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>J</kbd> | Ventana de recorte de encuadre de vídeo. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>L</kbd> | Ventana de velocidad de vídeo. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>S</kbd> | Visor de capturas de vídeo. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>O</kbd> | Organizador visual de PDF. |

## Dentro de las ventanas

| Ventana | Teclas |
|---|---|
| Cualquier editor | <kbd>↵</kbd> escribe la copia y nunca sobrescribe; <kbd>esc</kbd> vuelve. |
| Rueda de arrastre | Las flechas eligen, <kbd>↵</kbd> aplica, <kbd>esc</kbd> cancela; tocar <kbd>⇧</kbd>, <kbd>⌘</kbd> o <kbd>⌃</kbd> cambia de rueda. |
| Recorte y división de vídeo | <kbd>←</kbd> <kbd>→</kbd> avanzan un fotograma, <kbd>⇧</kbd> <kbd>←</kbd> <kbd>→</kbd> avanzan un segundo, <kbd>I</kbd> <kbd>O</kbd> fijan marcadores (recorte), <kbd>M</kbd> añade un corte y <kbd>⌫</kbd> quita el último (división), <kbd>Home</kbd> <kbd>End</kbd> saltan. |
| Organizador de PDF | <kbd>R</kbd> gira, <kbd>⇧</kbd> <kbd>R</kbd> gira en sentido contrario, <kbd>D</kbd> duplica, <kbd>⌫</kbd> elimina, <kbd>⌘</kbd> <kbd>←</kbd> <kbd>→</kbd> mueven la página. |
| Choose Order | <kbd>⌘</kbd> <kbd>↑</kbd> <kbd>⌘</kbd> <kbd>↓</kbd> mueven la fila. |

:::note[Intro sobre una selección de Finder]
<kbd>↵</kbd> sobre archivos seleccionados en Finder abre la rueda Convert en lugar de renombrar cuando activas Ajustes > General > «Enter on Finder selection» (desactivado por defecto, necesita Accesibilidad).
:::
