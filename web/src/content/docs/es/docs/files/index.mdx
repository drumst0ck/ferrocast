Ferrocast convierte imágenes, audio, vídeo, documentos, hojas de cálculo, subtítulos y carpetas, y los edita con 26 herramientas y 7 acciones de archivo, todo en tu Mac. No se sube nada. Primero se usan las herramientas de macOS (sips, afconvert, avconvert, textutil, ditto); ffmpeg, LibreOffice y cwebp son opcionales y, si falta una, se muestra su orden de instalación.

Arrastra archivos y pulsa una tecla: <kbd>⇧</kbd> **Shift** para conversiones, <kbd>⌘</kbd> **Command** para herramientas, <kbd>⌃</kbd> **Control** para acciones. También puedes pulsar <kbd>⌘</kbd> <kbd>T</kbd> sobre un resultado de archivo, ejecutar **Convert Files** o pulsar <kbd>⌥</kbd> <kbd>↵</kbd> sobre un resultado de archivo para abrir la rueda de formatos.

## Reglas de salida

El resultado se escribe junto al original con el mismo nombre base y la nueva extensión, y **nunca sobrescribe**: si ese nombre está ocupado añade 2, 3 y así sucesivamente. Un aviso muestra el resultado con la acción Reveal.

:::note[Intro sobre una selección de Finder]
Intro sobre una selección de Finder es un ajuste opcional en Ajustes > General («Enter on Finder selection», desactivado por defecto, necesita Accesibilidad): abre la rueda de conversión en lugar de renombrar. El comando Convert Finder Selection también funciona.
:::
