# Changelog

All notable changes to Ferrocast. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Also published at <https://ferrocast.app/changelog/> (feed: <https://ferrocast.app/changelog/rss.xml>).

Each entry is one bullet under a `###` category (`Added`, `Changed`, `Fixed`, `Removed`, `Security`, `Known limitations`). An optional `**Title**:` prefix becomes the entry title; optional trailing `#tags`, a `(docs: /docs/…)` link and a `{#slug}` permalink (kept when the title is edited) are read by `scripts/changelog/push.ts`.

## [Unreleased]

### Added
- **Sync, Forget this Mac**: Settings → Advanced → Sync lists the Macs that published sync data (name, last seen) and offers **Forget this Mac**, behind a confirmation, for every Mac but the one you are using. It removes that Mac's folder from the sync folder and this Mac stops reading it; if that Mac syncs again it reappears. (docs: /docs/launcher/sync/) #sync

### Changed
- **Sync, smaller clipboard documents**: each Mac's clipboard document holds only the entries copied on that Mac, so the size in iCloud Drive no longer grows with the number of Macs. Every Mac still gets the whole history, deleting an entry copied elsewhere still reaches every Mac, a Mac that loses its history recovers it, and v0.7.0 and older Macs keep working with the new documents. (docs: /docs/launcher/sync/) #sync
- **Sync, deletions are cleaned up**: a deletion is dropped from the documents once every Mac that is still live (published in the last 30 days, not forgotten) has published after it, instead of being kept for ever; never earlier, and the clipboard keeps its own 400-day rule. A Mac offline for more than 30 days no longer holds the clean-up back, so an item deleted meanwhile can return when it comes back. (docs: /docs/launcher/sync/) #sync

## [0.7.0] - 2026-11-10

### Added
- **Cookie consent on the website**: ferrocast.app no longer loads Google Tag Manager or sets Google Analytics cookies until you click Accept. The banner (English or Spanish, also on the docs) has Reject and Accept side by side, remembers your choice in this browser with the policy version, and a Cookie settings link in every footer reopens it. Rejecting stops Google from loading on the next page and removes the `_ga` cookies. New cookie policy pages: `/cookies/` and `/es/cookies/`. #website

### Changed
- **Sync speed**: the clipboard history is no longer serialised on the interface thread or while its lock is held, sync documents are written compact, and other Macs' documents that did not change are not read again. #sync
- **Extensions launching commands**: `launchCommand` now passes `type`, `context`, `arguments` and `fallbackText` to the launched command (`environment.launchType`, `props.launchType`, `props.launchContext`, `props.fallbackText`). `LaunchType.Background` runs it in a separate background process (the launcher and your current screen stay as they are; its HUD and errors are still shown, it is stopped after 60 s and when you quit; it cannot show views or dialogs), and a wrong type or context is rejected with an error. (docs: /docs/launcher/raycast-extensions/) #extensions
- **Switch Windows**: the list now includes windows on other Spaces and minimized windows, marked "Other Space", "Minimized" or "Hidden" (apps hidden with ⌘H) next to the app name. Choosing one unminimizes it and brings it forward, switching Space when needed. (docs: /docs/launcher/window-management/) #windows
- **Bringing apps to the front**: on macOS 14 and later Ferrocast uses the current activation API instead of the deprecated one for the launcher, Notes, the selector, pasting after hiding and app switching; macOS 13 keeps the previous behaviour. #launcher
- **Snippet dates follow the interface language**: `{date}`, `{day}`, `{datetime}` and date formats with month or weekday names (`MMMM`, `EEEE`) now use the names and the connecting word of the language set in Settings → General (Spanish, German, French, Portuguese, Japanese and Chinese included); numeric and ISO formats are unchanged. (docs: /docs/launcher/snippets/) #snippets
- **Translated messages**: about fifty error and status messages that appeared in English in every language (Compress, Redact, Bleep, Notion, translation results, tiling and volume titles, ChatGPT and Claude Code sign-in, unsupported extension screens and more) are now translated. #i18n
- **Intel Macs**: the docs now say the DMG/zip runs on Apple Silicon, and that Intel Macs can install with Homebrew, which builds from source for that Mac (not tested on Intel). #install

### Fixed
- **Sync, clock differences**: an edit or deletion made after receiving another Mac's version is no longer lost when this Mac's clock runs behind. #sync
- **Sync, notes edited on two Macs**: when both Macs edit the same note, the older text is kept as a new note marked "(conflict copy from <Mac>)" and Ferrocast shows a toast, instead of silently dropping it. (docs: /docs/launcher/sync/) #sync
- **Sync, a stuck iCloud file**: a file iCloud Drive has not downloaded is requested and skipped, and a run that does not answer in two minutes is given up and retried, so sync no longer stops for good. #sync
- **Sync, safer saving**: data files are flushed to disk and written through a unique temporary file, and a crash between saving data and the sync state makes the next run recover instead of publishing wrong edits. #sync
- **Sync, other fixes**: chats removed here only by the 200-chat limit are not deleted on your other Macs; this Mac's own documents wait for the next run when iCloud Drive is unavailable; the status line shows every failing part and "last sync" only moves when something synced. #sync
- **Sync, review follow-ups**: editing a note twice while another Mac sleeps no longer makes a false conflict copy, and a copy of trashed text stays in the trash; chats cut by the limit are remembered on disk at once; a Mac whose own document is still in iCloud waits for it instead of rebuilding without it; a data file that could not be saved is no longer later published as an edit; leftover temporary files are cleaned up; a same-size rewrite of another Mac's document is noticed; turning sync off clears old errors. #sync
- **Stray AI process**: when an AI or translation request failed right after starting, its curl or Claude Code process could be left running; it is now always stopped and cleaned up. #ai

### Security
- **Enforced Content-Security-Policy**: the website now sends its Content-Security-Policy as an enforced header instead of report-only, with every inline script allowed by hash, Google hosts allowed for analytics only after consent, and violation reports still sent to `/api/csp-report/`. No server setting is needed. #website

## [0.6.0] - 2026-11-09

### Added
- **Permission helper**: when Ferrocast opens the Accessibility, Screen Recording or Input Monitoring settings, a small panel with the Ferrocast icon appears next to System Settings; drag the icon into the list to add Ferrocast. (docs: /docs/getting-started/first-run/) #permissions
- **Move an app to the Trash**: right-click an application in the launcher (or press ⌘K) and choose Move to Trash (⌘⌫). It hides when nothing plays for a while and over full-screen apps. It uses the open-source mediaremote-adapter helper through macOS's own perl, needs no permission and may stop working after a macOS update; Ferrocast then says so once. (docs: /docs/launcher/notch-player/) #notch

## [0.5.0] - 2026-10-29

### Added
- **Interface languages**: Ferrocast now speaks Spanish, German, French, Brazilian Portuguese, Japanese and Simplified Chinese besides English. It follows the language order of macOS and you can pick another one in Settings → General → Language (System, English, Español, Deutsch, Français, Português (Brasil), 日本語, 简体中文); the change applies at once and is kept on each Mac, not synced. The launcher, built-in commands, Settings (search finds rows by their translated title and in English), the tour, the menu bar menu, notifications, the tool windows, the recording editor and the messages are translated; anything not translated yet shows in English. What you type (snippet, quicklink, note and script names) and what Raycast extensions show is never translated. (docs: /docs/launcher/settings/#language) #settings
- **Images in Notes**: paste a screenshot or image, drag image files onto a note, or choose Insert Image… (⇧⌘I or the right-click menu). PNG, JPEG, GIF, HEIC and WebP up to 20 MB are copied into an `attachments` folder in the data folder (named by content, so a repeated image is stored once), the note gets a standard relative Markdown link on its own line and the picture is drawn in the note up to 480 points wide. A bigger file or one that is not an image is refused with a message. Files no note links any more are deleted 7 days after their link was removed, so undo and Recently Deleted still find them. With sync on, note images travel through iCloud Drive as separate files: each Mac uploads only its own, a missing one is downloaded when a synced note links it, and an image is never removed while any Mac's notes link it. Notes in your Obsidian vault are not edited in this window, so nothing is copied into the vault. (docs: /docs/launcher/notes/) #notes

## [0.4.0] - 2026-10-28

### Added
- **Raycast extensions**: runs extensions you installed with Raycast (from ~/.config/raycast/extensions) in the launcher. Off by default: turn it on in Settings → Integrations → Raycast extensions, switch single extensions on or off there and edit their preferences in a form (passwords are masked). It needs Node.js 22 or newer; Ferrocast uses yours or downloads the official one (about 26 MB, checked against a built-in SHA-256) after you press the button. Ferrocast does not contact Raycast's Store and is not affiliated with Raycast. Extensions are third-party code that runs with your permissions and can read what you copy, the text you have selected and the list of apps you use.
