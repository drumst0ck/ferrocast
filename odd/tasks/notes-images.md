- L3 Implementation (T1-T3, T4 docs; commits 989e434, f3b6e22, 5b88eff, c64e606, 07637ab). Storage: notes are Markdown in `notes.json`, edited in a native NSTextView whose storage is built from `richtext::Doc`. Design: (a) model: `Style.image: Option<String>`; `![alt](src)` parses to one atomic span (alt = text; an empty alt becomes "image"), serializes back (a literal `!` before a link is escaped); (b) `core::attachments`: `<32 hex of sha256>.<ext>` names, type by magic bytes (PNG/JPEG/GIF/HEIC/WebP; HEIC is shown natively by NSImage, so no conversion), 20 MB cap checked before reading, a link resolves only if it is exactly `attachments/<valid name>` (no traversal, no absolute path, no URL, symlinks not followed), `referenced`, `cleanup` (7-day grace by mtime; re-pasting touches the file); (c) editor: an image is one U+FFFC character with an NSTextAttachment (attribute `fcImage` = source + alt, so it survives restyling), width min(natural, 480 pt x zoom, column), placeholder symbol when the file is missing, line height not stretched; paste (files, else picture without text), drag and drop at the drop point, Insert Image… (⇧⌘I, context menu) all call one host callback; (d) app: `NMsg::Images` stores files and inserts links after the cursor line, refused ones named in a toast; unlinked-file cleanup at most hourly off-thread (local notes incl. trash, plus every Mac's published notes when sync is on; skipped with no notes, a pending recovery, or an unreadable/placeholder remote notes document). Sync choice: per-device folders `devices/<id>/attachments/` (not one shared content-addressed folder) because each Mac writing only its own files is the existing guarantee against iCloud conflict copies; a Mac uploads a hash only when linked, present locally and held by no device folder; downloads from any folder after checking name = content hash; own-folder prune only when no merged/local/remote note links it, older than 7 days, not in a recovering run, and all remote docs readable and downloaded; `Outcome.attachments_added` redraws the open note.
