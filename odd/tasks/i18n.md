# Interface languages
Branch: feat/i18n · Status: in progress
Translate Ferrocast's interface into Spanish and the five most used other languages, following the system language with a manual choice in Settings.

## Specs
- S1 Notion "Mejoras Ferrocast / Añadir Idiomas a la herramienta" (verbatim): "Añadir los idiomas mas usados a la herramienta para conseguir mas usuarios".
- S2 User choice (L2, verbatim option): "Español + 5 más usados" — "Español, alemán, francés, portugués (Brasil), japonés y chino simplificado. Traducción hecha por mí; sigue el idioma del sistema con opción de cambiarlo en Ajustes."
- S3 English stays the source and the fallback for any missing string; nothing changes for English users.

- T1 S2 S3 i18n infrastructure: string catalog, locale detection from macOS, Settings → General language picker (System + 7), fallback to English; tests. — done (9d12f19 core layer, setting, search; 3dc0c1b picker, live apply, CJK font)
- T2 S2 Extract every user-visible string (launcher, settings, notes, tour, menus, toasts, notifications) into the catalog. — done (3dc0c1b, 9d12f19, 64ec0f7, b972ec9, a338cdc; Annotate tools/buttons, the Capture footer and the native overlay/notice/system/window texts in the working tree, commit pending with the parent). Deliberate exceptions: Raycast-extension forms that come from the extension, keywords (English by design), diagnostics/log lines, helper/OS error text, file and user names
- T3 S2 Translations es, de, fr, pt-BR, ja, zh-Hans; layout checks for long strings and CJK fonts. — done: 1714 rows, every cell filled in all 7 columns; layout and font checks in the app/core tests
