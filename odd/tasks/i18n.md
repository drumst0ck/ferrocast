# Interface languages
Branch: feat/i18n · Status: in progress
Translate Ferrocast's interface into Spanish and the five most used other languages, following the system language with a manual choice in Settings.

## Specs
- S1 Notion "Mejoras Ferrocast / Añadir Idiomas a la herramienta" (verbatim): "Añadir los idiomas mas usados a la herramienta para conseguir mas usuarios".
- S2 User choice (L2, verbatim option): "Español + 5 más usados" — "Español, alemán, francés, portugués (Brasil), japonés y chino simplificado. Traducción hecha por mí; sigue el idioma del sistema con opción de cambiarlo en Ajustes."
- S3 English stays the source and the fallback for any missing string; nothing changes for English users.
