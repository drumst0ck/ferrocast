# owner-decisions-2
Second batch of owner decisions after release v0.7.0: a universal (Apple Silicon + Intel) download and two sync improvements deferred in owner-decisions-1 (L7).
Base: master after v0.7.0. One PR per task, test-first, independent verify (release/CI and sync are high risk), merge on green CI.

## Specs
- S1 Publish 0.7.0: "1 si" — run scripts/release.sh 0.7.0 (done by the parent).
- S2 Universal download: "2 si" — the release DMG/zip runs natively on Apple Silicon and Intel Macs: the app binary and every helper (Translate, Capture, MediaRemoteAdapter, anything else Mach-O in the bundle) are universal (arm64 + x86_64), built by cross-compiling on the arm64 runner; a release step fails if any Mach-O in the bundle lacks either architecture; Homebrew source builds keep building for the host only; docs (README en/es, CONTRIBUTING, website install/build-from-source/FAQ/docs index en+es, SEO components) say the download runs on Apple Silicon and Intel, and that Intel is not tested on real hardware.
- S3 "3, da igual" — Mb/Mbps units, VoiceOver and proxy compression: no change.
- S4 Sync clipboard document: "4 si" — each Mac's clipboard sync document holds only the entries copied on that Mac (not entries adopted from other Macs), so iCloud size no longer grows with the number of Macs; existing data keeps working: v0.7.0 and older Macs still merge, no entry is lost or resurrected during the transition, and recovery of a lost local history still works.
- S5 Forget this Mac: "4 si" — Settings → Sync lists the Macs that have published sync data (name, last seen) and offers "Forget this Mac" for another Mac (not the current one) with a confirmation; forgetting removes its documents from the sync folder so they are no longer read; tombstones (deletion records) are garbage-collected once every live Mac has published past them, so they stop growing forever; translated texts in all languages; docs updated.
- S6 Deletion cleanup: "haz limpieza" — tombstones are collected safely with acknowledgements: each sync document carries its writer's written_at and, per peer, the written_at of that peer's document it last merged cleanly; a Mac drops a deletion stamped t only when every Mac that is not forgotten acknowledges this Mac's document written at or after t (only this Mac's own clock is compared); a Mac that never acknowledges (old build, offline forever) blocks collection until it is forgotten; no item a peer still holds or a user edited is ever removed; v0.7.0/v0.8.0 documents stay compatible.
- S7 Publish the next version: "publica siguiente version" — merge #146 and #145, then release 0.8.0.
