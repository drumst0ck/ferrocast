# Mejoras Ferrocast: permissions helper, move app to Trash, notch now playing
Branches: one per task off origin/master, each in its own worktree; one PR each · Status: done (PRs #105, #106, #108 merged; changelog for #99 in #107)
Three "Idea" cards from the Notion "Mejoras Ferrocast / Ideas de Ferrocast" board (created 2026-10-29/30).

## Specs
- S1 Card "Para añadir ferrocast a los permisos" (Prioridad Alta), Detalles verbatim: "Para añadir ferrocast a los permisos, que se habra una ventana en la que puedas arrastrar ferrocast a la lista de permisos y pueda ser comodo para el usuario". Agreed reading (user: "1 si"): open the right System Settings privacy pane and, next to it, a small window with the Ferrocast icon that the user can drag into the permission list, as other Mac apps do.
- S2 Card "Poder borrar apps desde el buscador dando click derecho" (Prioridad Alta), no details. User: "2 que se mueva a la papelera". Agreed reading: right click on an app in the launcher results offers moving the app to the Trash (with confirmation); only the .app bundle, nothing in ~/Library; never a permanent delete.
- S3 Card "Reproductor de sonidos en el notch" (Prioridad Media), no details. User: "3.si es eso, pero demosle un estilo moderno y que tenga que ver con la app". Then (L6): "debemos cubrir los navegadores y cualquier cosa que suene en el pc que venga de navegador reproductor etc", and the user chose "Solo mediaremote-adapter" (L7). Agreed reading: show what is playing from ANY source (browsers, Spotify, Music, Podcasts, VLC…) in the notch with play/pause, previous and next, like NotchNook or Alcove, with a modern look that matches Ferrocast's own style; the only source is ungive/mediaremote-adapter (BSD-3, runs MediaRemote through /usr/bin/perl); no AppleScript/Spotify/Music fallback.
- S4 Repository rules: tests with each behavior (test-first where deterministic), docs and help text updated when user-facing behavior changes, interface strings translated in crates/core/src/i18n/strings.tsv for all 7 languages, `cargo test --workspace`, clippy and `cargo fmt` clean.
