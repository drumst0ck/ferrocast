# File tools (Tangerine-style converter and file actions) in Ferrocast
Branch: feat/ui-polish-and-fixes · Owner: parent session · Status: in progress
Goal: bring Tangerine for Mac's capabilities into Ferrocast, local-only, same interaction model (drag + key → wheel), without its brand or assets.

## Specs
- S1 User request (verbatim, L1): "vamos a incluir en nuestra app las funcionalidades de este programa https://tangerineformac.com/ todas, y de la misma manera, basicamente la copiaremos para incluirla y hacer nuestro ferrocat mas potente".
- S2 Tangerine's model (from its site, 2026-10-18): "Drag a file, tap Shift, and drop. Turn files into the formats you need without breaking your flow." "Everything happens locally on your Mac." "Start dragging, then tap a key. The wheel stays open until you drop. Change the keys in Settings."
- S3 Conversions: "Across images, video, audio, documents, spreadsheets, and archives." Formats listed: Images "JPG PNG WebP HEIC TIFF AVIF BMP"; Audio "MP3 M4A WAV FLAC OGG Opus AIFF WMA"; Video "MP4 MOV MKV WebM AVI WMV GIF"; PDF "PDF → DOCX PAGES PPTX XLSX JPG PNG EPUB TXT MD"; Documents "DOCX PAGES Markdown TXT EPUB"; Slides "PPT / PPTX → PDF JPG PNG"; Spreadsheets "XLSX ODS CSV TSV"; Subtitles "SRT VTT"; Archives "ZIP TAR GZIP".
- S4 File tools: "Compress, crop, trim, split, merge, and more." Image tools: Compress images ("Choose a target file size, percentage reduction, or preset. Resize while compressing"), Edit metadata ("Edit camera and location tags, or remove metadata"), Edit photos, Annotate photos, Add a background, Crop images ("Choose an aspect ratio or enter exact output dimensions"), Redact photos ("Detect faces or text locally, then cover"), Create a PDF ("Combine selected images into one PDF, with a page per image"), Make a collage.
- S5 File actions ("Drag any file or folder, then tap Control."): AirDrop, Float ("Keep files in a floating shelf. Pin it to a screen edge"), Copy ("Copy files to the clipboard, ready to paste in Finder"), Move ("Choose a destination folder and move the originals there"), Copy Path ("one path per line for a selection"), Terminal ("Open a folder, or a file’s containing folder, in Terminal or iTerm2"). "Works with folders, mixed selections, and files that have no conversion tools."
- S6 Engine constraint (decision): conversions run with tools present on every Mac (sips, afconvert, avconvert, textutil, ditto/zip/tar) and use ffmpeg / LibreOffice only when installed, with a clear hint otherwise. Nothing is uploaded.
- S8 Interaction (site, 2026-10-19): "Drag a file, then tap Shift for conversions, Command for file tools, or Control for actions. Release the key and keep dragging; the wheel stays open until you drop or cancel. Or press Enter on a file to open the format menu, then use Command or Control to switch wheels. Use arrow keys to choose, Enter to apply, and Escape to cancel."
- S9 Counts and extras (site): "275 Conversion options", "26 Advanced file tools", "6 File actions"; "Convert, compress, crop, trim, split, and merge". Format notes: Images "PDF export · SVG input only"; Video "MP3 export"; PDF "All pages · images at 300 DPI"; Documents "RTF, RTFD & text clippings input · HTML export"; Slides "PPT input only · PDF to PPTX"; Spreadsheets "PDF export · XLS input only"; Subtitles "TXT export"; Archives "RAR input only".
- S10 Tangerine's exact data (extracted 2026-10-19 from tangerineformac.com/assets/home-*.js and tools-*.js; node count = 275 over 46 inputs). Conversion matrix z(format): images [jpg png webp heic tiff svg avif bmp] → [jpg png webp heic tiff avif bmp pdf]; audio [mp3 m4a wav flac ogg opus aiff wma] → the other 7; video [mp4 mov mkv webm avi wmv] → the other 5 + gif + mp3; gif → [mp4 mov mkv webm avi wmv]; docs [docx pages md rtf rtfd textClipping] → [docx pages pdf txt md html epub png jpg] minus self and minus outputs rtf/rtfd/textClipping; sheets [xlsx xls ods csv tsv] → [xlsx xls ods csv tsv pdf] minus self and minus output xls; subtitles [srt vtt] → [srt vtt txt]; pdf → [docx pages pptx xlsx jpg png epub txt md]; ppt/pptx → [pdf jpg png]; epub → [pdf docx pages txt md html]; txt → [docx pages pdf md html epub jpg png]; archives [zip tar gz rar] → [zip tar gz] minus self (rar input only; gz = tar.gz). Output-only exclusions: rar ppt xls rtf rtfd textClipping.
- S11 Tangerine's 22 tool windows: compress (target size or % reduction, resize images while compressing); removeMetadata "Edit metadata" (inspect/change/remove; fields grouped by file/track/chapter); editImage (dehaze, clarity, grain, noise reduction, light/colour/detail, live preview); annotateImage (arrows, text, shapes, callouts, numbered labels, magnifiers, images, draw/highlight); frameImage "Add a background" (another image as background, blur, rounded corners, shadow); cropImage (exact pixels, preset/custom aspect ratios); redactImage (detect faces/text, solid colour or blur, several movable areas); createCollage (grid/row/column/featured, final size, spacing, corners, background); trimVideo (frame stepping, timecodes); cropVideo (exact dimensions, keep audio); changeVideoSpeed (slower/faster, preserve pitch, silent videos); joinVideos (MP4/MOV/MKV into one MP4, first clip as canvas); videoSnapshots (exact frames → full-resolution PNG); splitVideo (custom points or equal parts, all clips in one folder); redactVideo (per-redaction time range, solid/blur); normalizeAudio (loudness range, true peak, compare levels); audioToVideo "audio visualizer" (waveform or still image, landscape/portrait/square MP4); trimAudio (waveform, remove silence at start/end, exact times); audioChannels (mono/stereo, per-channel volume); redactAudio "Bleep audio"; mergePDF (Finder order, reorder); organizePDF (rotate, duplicate, remove, reorder pages). Also in the wheel: muteVideo, splitPDF, createPDF, extractArchive. Tools by format (et()): jpg/png/webp/heic/tiff → compress, removeMetadata, editImage, annotateImage, frameImage, cropImage, redactImage (multi: compress, removeMetadata, cropImage, createPDF, createCollage); svg multi → createPDF, createCollage; mp3/m4a/wav/flac → compress, removeMetadata, normalizeAudio, audioToVideo, trimAudio, audioChannels, redactAudio; mp4/mov/mkv → compress, removeMetadata, muteVideo, trimVideo, cropVideo, changeVideoSpeed, videoSnapshots, splitVideo, redactVideo (multi: compress, removeMetadata, muteVideo, trimVideo, cropVideo, changeVideoSpeed, joinVideos); gif → removeMetadata; pdf → compress, removeMetadata, splitPDF, organizePDF (multi: compress, removeMetadata, splitPDF, mergePDF); archives → extractArchive. Keys: Shift conversions, Command tools, Control actions. Wheel actions: airDrop, float, copy, move, copyPath, openTerminal.
- S7 Output: next to the original, same base name, new extension; never overwrite (append " 2", " 3"…). Toast with result and a Reveal action.
