# owner-decisions-1
Implements the owner's answers to the pending decisions left after release 0.6.0 (odd/tasks/bugs-round-5.md L10), plus the low-risk leftovers offered in the same message.
Base: master 98b4d12 (v0.6.0 released). One PR per group, test-first, independent verify for high-risk (web consent/CSP, sync, macOS activation), merge on green CI.

## Specs
- S1 Cookies: "cookies cumple la ley europea" — the website must comply with EU cookie law (ePrivacy/GDPR, Spain LSSI/AEPD guidance): no analytics cookies or GTM/GA4 loading before explicit opt-in; banner with Accept and Reject equally prominent; the choice is stored and can be changed later from a footer link; a cookie policy page in English and Spanish listing the cookies; Spanish pages show Spanish texts.
- S2 CSP: "el csp hazlo sin que yo tenga que hacer nada" — switch the website Content-Security-Policy from Report-Only to enforced, with no manual step for the owner, after making sure every page (including GTM after consent, the home demo, docs search, changelog) works under it; keep violation reporting.
- S3 "no hace falta traducitrlo" — the Spanish home demo example phrases stay as they are (no change).
- S4 Intel: "revisa si esta soportado intel" — determine whether Ferrocast runs on Intel Macs (release DMG/zip architecture, Homebrew source build, helpers, Node runtime) and make README.md, README.es.md, CONTRIBUTING.md, Formula and CHANGELOG say the same true thing.
- S5 Units: "ton significa 1000kg" — `ton` converts as 1000 kg (metric tonne); confirm and pin with a test.
- S6 Dates: "si traduce las fechas" — `{date}`, `{day}`, `{datetime}` and similar placeholders use month/day names and connecting words of the interface language.
- S7 Activation: "actualiza la opcion de traer la app al frente" — on macOS 14+ use the non-deprecated activation API instead of ActivateIgnoringOtherApps, keeping older macOS working (paste-after-hide, app switching).
- S8 Switch Windows: "si debe incluirlas" — Switch Windows also lists windows on other Spaces and minimized windows, and choosing one brings it forward (switching Space / unminimizing).
- S9 "no va a haber nunca developer id, no voy a pagar por ello" — drop the codesign Team ID idea; no Developer ID work.
- S10 Extensions: "arregla lo de las extensiones" — `launchCommand` passes `type` (LaunchType.UserInitiated / Background) and `launchContext` to the launched command (`environment.launchType`, `props.launchContext`) like Raycast.
- S11 "da igual el nombre de las grabaciones" — recording folder names unchanged.
- S12 Sync: "revisa la sincronizacion para mejorarla" — review iCloud/folder sync (settings, clipboard, notes, snippets, etc.) for bugs, data-loss risks and performance, then fix what is found (e.g. clipboard change detection without re-serialising 1000 entries on the UI thread).
- S13 Leftovers offered before: translate the 53 KNOWN_ENGLISH_ONLY sentences (crates/app/src/i18n_scan_tests.rs) and reap the AI child process in translations (`ai_stream_system`, AiCancel::default never cancels, early `?` returns after attach).
